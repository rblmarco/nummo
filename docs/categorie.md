## Regole e tag nelle note

- **Casa** = casa in cui si vive ora. **Immobili** = immobili dati in affitto (con tag dell'immobile).
- I tag si scrivono nella nota con `#`:
  - `#straordinaria`: esclusa dai totali della dashboard, se l'interruttore è spento.
  - Veicoli: `#scooter`, `#moto`, `#auto1`, `#auto2`.
  - Immobile in affitto: `#casa2`.
- Nell'app, categorie, conti e tag vengono dai fogli Categorie, Conti e Tag: questo file serve solo a compilarli la prima volta.
